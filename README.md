# synths

[![MIT licence](https://img.shields.io/badge/licence-MIT-green)](LICENSE)

synths is for making sounds and music in Python: synths, samples, effects and tracker songs, for games and for the fun of it. It is the sound sibling of [Pyctures](https://github.com/johnwylie70/pyctures), designed for projects made in [Circuitry Studio](https://www.circuitry.dev).

```python
import synths
```

Nothing here is ready to use yet.

Prefer JavaScript? [synths.js](https://github.com/johnwylie70/synths.js) is the same library for JavaScript.

The sound engine itself is [synths-core](https://github.com/johnwylie70/synths-core).
